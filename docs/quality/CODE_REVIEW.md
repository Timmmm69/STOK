# Code review

Reviewer сначала сверяет intent с active plan и Product Compass, затем проверяет diff как систему:

- Scope: нет ли функции/абстракции следующего среза.
- Правила: один смысл во flow, ID, коде и тестах; гипотеза не стала фактом.
- Границы: transport тонкий, application координирует, infrastructure скрыта, deep imports/циклы отсутствуют.
- Данные: migration безопасна; деньги, tenant scope, транзакция, idempotency и correction рассмотрены.
- Ошибки: нет ложного успеха, секретов/PII, сырых исключений и проглоченных отказов.
- Тесты: проверяют happy/negative/repeat, не зависят от порядка/sleep, используют реальную БД где нужно.
- Эксплуатация: setup, CI, observability, backup/recovery и Windows/Linux различия обновлены.
- Evidence: заявлены только фактически запущенные команды.

Замечание не закрывается ослаблением gate без исправления причины или отдельного ADR с равноценной защитой.
