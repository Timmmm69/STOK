# Definition of Done

Изменение завершено, когда:

- есть пользовательский/технический результат и явные границы;
- прочитаны релевантные Compass, правила, архитектура и active plan;
- правило имеет ID, критерии и негативные/повторные сценарии;
- UI не обходит application service, модуль не обходит публичные границы;
- данные имеют migration, constraints, tenant/деньги/историю/идемпотентность по необходимости;
- тесты доказывают поведение на правильном уровне и могут реально упасть;
- безопасность, логи, error response и recovery рассмотрены;
- документация, ADR и runbook обновлены вместе с кодом;
- `pnpm format`, `pnpm check` и требуемые full/integration/E2E команды фактически прошли;
- diff просмотрен без секретов, случайных env, generated/build artifacts и scope creep;
- execution plan содержит фактические результаты, а не заявления.

Отключённый тест/линтер, `any`, непроверенный client `organization_id`, `float` для денег, бесследное удаление факта или «будущая» абстракция означают, что задача не готова.
