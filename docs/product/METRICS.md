Статус: нормативные определения пилота; baseline и окончательные пороги подтверждаются полем.

| ID                     | Метрика и формула                                                                                              | Предварительная цель / решение               |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| `METRIC-PILOT-NSM-001` | Вещи пилота с непрерывной связью партия–цена–итоговый сверенный статус / все физические вещи пилота            | ≥ 98%                                        |
| `METRIC-PILOT-002`     | Продажи, полностью проведённые через систему / все фактические продажи пилота                                  | ≥ 98%                                        |

| `METRIC-PILOT-004`     | Повторные сущности от одного idempotency key                                                                   | 0                                            |

## Правила измерения

Каждая запись содержит окно, источник, владельца, единицу и исключения. Время терминала исключается из `METRIC-PILOT-003`, но измеряется отдельно. Продажи вне системы восстанавливаются из независимой сверки, а не исчезают из знаменателя. Нулевое расхождение после ручной корректировки не считается исходным нулём: сохраняются первоначальное значение и действие разбора.

Показатели партии сравниваются на одинаковом возрасте (7, 14, 30 дней). Категории сравниваются относительно доступного остатка, а не только абсолютной выручки. Уровень доверия определяется [DATA_QUALITY.md](DATA_QUALITY.md).
