# Проектирование STOK

Дизайн идёт на один подробный срез впереди разработки:

1. владелец утверждает функции и переходы;
2. выбирает один из трёх визуальных вариантов;
3. проверяет живой макет;
4. только после этого начинается реализация.

Карта всего пилота задаёт связность продукта, но не является обещанием детально реализовать дальние экраны без полевой проверки. Выбранные изображения, ссылка на макет, решения владельца и результаты UX-ревью сохраняются здесь и связываются с карточками доски.
