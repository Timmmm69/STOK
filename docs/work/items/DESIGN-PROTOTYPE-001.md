# DESIGN-PROTOTYPE-001: Живой макет категорий и цен

## Цель

Создать отдельный кликабельный макет ближайшего рабочего среза без подключения к рабочей базе.

## Пользовательский результат

Владелец проходит создание и изменение категорий и цен до начала разработки.

## Зависимости

- `DESIGN-VISUAL-001`

## Критерии приёмки

- [x] Работают список, создание, изменение, архивирование и восстановление.
- [x] Показаны пустое, успешное и ошибочное состояния.
- [x] Есть защита несохранённых изменений.
- [x] Остальные разделы пилота доступны на уровне навигации и не ведут в тупик.
- [x] Путь не имеет тупиков на ноутбуке и узком экране.
- [ ] Макет утверждён владельцем.

## Проверки

Модульные проверки макета: 6 из 6. Сборка макета успешна. Сценарии создания, изменения, дубля, ошибочного сохранения, безопасного повтора, архива, восстановления, пустого состояния и защиты изменений пройдены в браузере. Проверены размеры 1440×1024 и 390×844 без горизонтальной прокрутки.
