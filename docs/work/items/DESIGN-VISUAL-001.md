# DESIGN-VISUAL-001: Три визуальных направления STOK

## Цель

Выбрать визуальный язык общей оболочки и экрана категорий/цен.

## Пользовательский результат

Владелец сравнивает три реально различающихся направления и выбирает одно.

## Зависимости

- `DESIGN-FLOW-001`

## Критерии приёмки

- [x] Созданы ровно три независимых варианта 1440×1024.
- [x] Варианты отличаются иерархией и рабочей компоновкой, а не только цветом.
- [x] Учтены скорость, читаемость, ошибки, сканер и принтер.
- [ ] Выбор владельца записан в репозитории.

## Ревью

Три варианта прошли предварительную визуальную проверку. Требуется выбор владельца.

## Следующее действие

Владельцу выбрать вариант 1, 2 или 3 либо перечислить изменения.
