# Управление работой STOK

Этот каталог позволяет продолжать продукт в новом чате без пересказа переписки. Источник истины — карточки в `items/`; `BOARD.md` собирается из них автоматически. GitHub Project показывает те же карточки, но не заменяет репозиторий.

## Начало нового чата

1. Прочитать `AGENTS.md`.
2. Прочитать `BOARD.md` и найти карточку с пометкой «главная».
3. Прочитать `HANDOFF.md`, главную карточку и связанный активный план.
4. Проверить Git и фактическое состояние, не полагаясь только на передачу.
5. Продолжать только следующее действие главной карточки.

Короткая инструкция для нового чата:

> Продолжи STOK по репозиторию. Сначала прочитай AGENTS.md, docs/work/BOARD.md, docs/work/HANDOFF.md, главную карточку и активный execution plan. Проверь Git и не доверяй непроверенным заявлениям. Выполни только следующее действие главной карточки, затем обнови карточку, HANDOFF, доказательства, ревью и Git.

## Изменение состояния

1. Изменить блок `WORK_ITEM` и содержимое карточки.
2. Если меняется главная задача, снять `primary: true` со старой и поставить новой.
3. Выполнить `pnpm work:render`.
4. Выполнить `pnpm work:check` и остальные проверки задачи.
5. Обновить `HANDOFF.md` и записать фактический коммит после его создания.
6. После фиксации в Git выполнить предварительный просмотр `pnpm work:github:plan`, затем явное применение `pnpm work:github:apply`.

Одновременно существует ровно одна главная карточка. Состояние «Готово» требует ссылки на существующий файл ревью и хотя бы одного доказательства в метаданных карточки.

## Состояния

- **Очередь** — работа признана нужной, но ещё не детализируется.
- **Нужно решение** — без решения владельца или исследования нельзя безопасно планировать.
- **Проектирование** — уточняются функции, правила или дизайн.
- **Готово к разработке** — решения и критерии утверждены.
- **В работе** — выполняется реализация.
- **Проверка** — результат создан и независимо проверяется.
- **Ждёт владельца** — требуется действие или утверждение владельца.
- **Заблокировано** — есть внешний блокирующий фактор и указан способ разблокировки.
- **Готово** — критерии, проверки, ревью и доказательства согласованы.

## GitHub

Синхронизация односторонняя. Комментарии GitHub допустимы, но состояние меняется только через карточку и новый коммит. Команда предварительного просмотра ничего не меняет. Команда применения создаёт или обновляет задачи и добавляет их в проект `STOK — разработка`; повторный запуск использует ID карточки и не создаёт дубль.
