# Контекст системы

Статус: нормативная граница целевой системы и текущего harness.

## Люди и внешние системы

- Собственник, продавец и сотрудник приёмки используют один web-интерфейс; на старте роли могут совмещаться.
- PostgreSQL хранит операционные факты и проекции.
- USB/сетевой принтер и сканер — внешнее магазинное оборудование; конкретные модели открыты.
- Банковский терминал в пилоте не интегрирован программно: продавец вручную подтверждает результат, а закрытие смены сверяет итог.
- Фискальная система, production hosting, backup и ИИ/API находятся вне текущего harness и требуют отдельных решений.

## Граница текущей поставки

Один Node.js-процесс Next.js обслуживает UI, route handlers и application services; один PostgreSQL хранит данные. `/health` — единственная реализованная страница и endpoint. Он доказывает запуск и соединение, но не готовность магазина, безопасность SaaS или production SLO.

## Будущее направление

Первый продуктовый поток развивается внутри того же модульного монолита. Внешний сервис появляется только при измеренном требовании к независимому масштабированию/отказу или аппаратной локальности. Наиболее вероятный кандидат — локальный печатный bridge, но решение откладывается до теста оборудования.
