# Границы ИИ

Статус: нормативное ограничение будущего направления; ИИ отсутствует в пилоте и harness.

Детерминированный код считает продажи, остатки, деньги, проценты, сроки и расхождения. ИИ получает только рассчитанные и разрешённые данные, объясняет, формирует гипотезы и предлагает действия.

ИИ не является источником истины, не меняет цены, не проводит/отменяет продажи, не списывает товар, не создаёт расходы, не обвиняет сотрудников и не определяет кражу. Будущее действие требует preview, подтверждение уполномоченного человека, idempotency и audit.

Эволюция: ручной экспорт агрегатов → автоматический недельный отчёт → встроенный помощник → подтверждаемые предложения. Каждый этап требует оценки персональных данных, prompt-injection, стоимости, воспроизводимости и качества ответа.
